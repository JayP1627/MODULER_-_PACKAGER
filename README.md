# Multi-Utility Toolkit

A menu-driven Python project that demonstrates the use of built-in modules and custom modules. It provides utilities for date and time operations, mathematical calculations, random data generation, UUID generation, file handling, and exploring module attributes using `dir()`.

## Concepts Used

* Python Modules and Packages
* Import Statement
* Functions and Loops
* File Handling
* Exception Handling
